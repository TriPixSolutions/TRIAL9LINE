# Home hero — reference implementation

The supplied reference guided the dark navy/purple composition, split desktop arrangement, large sans serif headline with an underline, studio equipment scene, translucent floating cards and rounded header CTA. All text, cards and actions are live HTML. Client-facing business statistics were not supplied, so the scene uses service descriptions rather than invented performance claims. The Explore our work action opens /work, rather than pretending to play an unavailable showreel.

The supplied brand symbol was reproduced as a small SVG for a transparent, scalable header mark. Home uses white; interior pages use a dark version. The remainder of the public Home page and the CMS were preserved.
